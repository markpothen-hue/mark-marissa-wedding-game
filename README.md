# Mark & Marissa's Adventure

A wedding arcade game in four levels, each a different kind of game (inspired by Cheese Quest):

1. **Fort Lee to Blue Angel**: platformer
2. **Chinatown Dash**: runner
3. **Central Park Ride**: bike lane-dodger
4. **Bear Mountain**: magic-carpet shooter with a boss

Built with React + Vite + Phaser 3.

```bash
npm install
npm run dev -- --host   # play on phones on the same Wi-Fi via the Network URL
```

Sprites in `public/assets/px/` are generated from the painted art by `python3 tools/build_sprites.py`.
